what is this site?
- a site that allow event-owner to host a bidding-event
- a site that allow user to bid on item

- anyone can register account
- to bid on an event, user must be approved by event-owner
- the site will have online payment in the future
- to host the event, event-owner must contact to admin to register account and event
- site-event has dashboard to monitor and manage event 
- 

0. Entity
    - event-owner
    - user
    - bidder
    - contributor (artist, author, ...)
    - product (art, gallery, book, ...)


1. modules:
    - event-owner registration: contact to Administrator with required information to be able has an account to host an event
    - user registration: can register by email
    - bidder: use registered-account to request event-owner to be able place a bid
    - 

2. functions for each users type
    - event-owner
        - host event
        - approve Bidder
        - register Contributor
        - register product
        - extract data
        
    - user
        - view event
        - view product
        - view contributor

    - bidder
        - place a bid
        - receive bidding price update
        - cancel bid
