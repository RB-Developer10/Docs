
## User Type

- User

- Event owner

- Bidder

- Contributor

### User

Anyone can register an account with email verification to become a `User`. `User` can view and explore the event. `User` can not place a bid.

### Event Owner

Anyone can regsiter as an `Event Owner` by contacting to `System Administrator`.

`Event Owner` can manage event information, register `Contributor`, register `Product` for bidding, extract `Event Data`, and approve `Bidder`.

### Bidder

To become a `Bidder`, `User` must request `Event Owner` to become a `Bidder` for the specifc `event`.

### Contributor

`Contributor` is a person whose `Event Owner` registered into their `event`.

## What each User Type able to do

### User

- View Event

- View Bidding Information

### Event Owner

- Manage Event Information

- Approve normal `User` request to become a `Bidder` for the Event

- Remove `Bidder`

- Register `Contributor` information in the Event

- Extract Event information data

### Bidder

- Place a bid

- Cancel a bid

- Recieve bidding price update

## Bidding Flow

- A person register an account then become a `User`

- A `User` request to `Event Owner` to be able place a bid

- `Event Owner` approve the request, then a `User` become a `Bidder`

- A `Bidder` receive notification by email on any Bidding price update

- Bidding will be closed when the event reach the end date

- Winner wil be announce as public or not depend on `Event Owner`'s choice

- A `Bidder` recieve the product by contact to `Event Owner` or come to the event physically.
